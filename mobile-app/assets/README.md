# Assets Folder

This folder should contain your app icons and splash screens.

## Required Files

- `icon.png` - App icon (1024x1024px)
- `splash.png` - Splash screen (1242x2436px)
- `adaptive-icon.png` - Android adaptive icon (1024x1024px)
- `favicon.png` - Web favicon (48x48px)

## Quick Setup

You can use placeholder images for now. Expo will generate the required sizes automatically.

### Option 1: Use Expo's default assets
The app will work with default Expo assets if you don't provide custom ones.

### Option 2: Create custom assets
1. Create a 1024x1024px PNG for your app icon
2. Create a 1242x2436px PNG for splash screen
3. Place them in this folder with the names above

### Option 3: Use online tools
- https://www.appicon.co/ - Generate all icon sizes
- https://www.figma.com/ - Design custom icons
- https://www.canva.com/ - Easy icon creation

## 🚀 Get Started in 2 Minutes

### 1. Install Dependencies

```bash
cd mobile-app
npm install
```

### 2. Start the App

```bash
npm start
```

### 3. Test on Your Phone

1. Install **Expo Go** app:
   - [iOS App Store](https://apps.apple.com/app/expo-go/id982107779)
   - [Android Play Store](https://play.google.com/store/apps/details?id=host.exp.exponent)

2. Scan the QR code shown in terminal

3. **Done!** Your app is running and connected to your backend

## 🐛 Troubleshooting

### App loads but can't send messages?

Your Hugging Face Space might be sleeping. First message may take 30-60 seconds to wake it up.

### QR code not working?

Make sure:
1. Expo Go app is installed on your phone
2. Phone and computer are on same WiFi
3. Try typing the URL manually in Expo Go

### Build errors?

```bash
# Clear everything and reinstall
rm -rf node_modules
npm install
expo start -c
```

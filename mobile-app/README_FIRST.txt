⚠️  IMPORTANT: Fix File Limit Error First!
==========================================

You're seeing "EMFILE: too many open files" error.

QUICK FIX (Mac):
----------------

1. Install Watchman (recommended):
   brew install watchman

2. OR increase file limit:
   ulimit -n 65536

3. Then start the app:
   npm start

📖 See FIX_MAC_FILE_LIMIT.md for detailed instructions


🚀 QUICK START (After fixing file limit)
=========================================

1. Install dependencies:
   npm install

2. Start the app:
   npm start

3. On your phone:
   - Install "Expo Go" app
   - Scan the QR code
   - Done!
